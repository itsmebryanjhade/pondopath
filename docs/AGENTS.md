# Documentation scope

- Use [the index](README.md) to locate the relevant page; read metadata/headings before long plans. Do not load all documentation for an unrelated task.
- Preserve names, amounts, dates, commands, limits, uncertainty and authorization boundaries when editing prose. Requirements, dated plans and measured evidence are different kinds of records.
- Keep the PRD's canonical filename, `superpowers/` history and machine-written evidence paths stable. PRD contents are version 1.1 even though its filename says v1.0.
- Put research in `research/`, agent-operation references in `agents/`, and current technical guidance in the topical pages. Update incoming/outgoing links when moving a maintained page.
- Do not edit ignored `.superpowers/`, `.taste-skill/` or generated Graphify artifacts as if they were maintained source documentation.
- Documentation-only verification is local links/anchors, preserved content and Markdown/whitespace checks. Do not run app suites, reseed data, evaluate paid AI or launch workers for a prose-only change.
